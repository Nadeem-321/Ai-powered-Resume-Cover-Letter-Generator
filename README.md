# 🚀 AI Resume & Cover Letter Generator

## 📌 Project Overview

The **AI Resume & Cover Letter Generator** is a web-based application that automatically generates professional resumes and job-specific cover letters using user input. This system simplifies the process of creating structured and professional job documents using Artificial Intelligence concepts and Natural Language Processing techniques.

This project is developed as part of **Project Based Experiential Learning  and demonstrates the practical implementation of AI in document generation.

The application collects user details such as personal information, education, skills, and work experience, and generates a well-structured professional resume along with a customized cover letter.

---

## 🎯 Problem Statement

Many students and job seekers face difficulty in writing professional resumes and cover letters. Creating these documents manually requires time, proper formatting, and professional writing skills.

This project aims to:

* Automate resume creation
* Generate professional cover letters
* Reduce manual effort
* Provide structured job documents instantly

---

## 🎯 Objectives

* To develop an AI-based resume generator
* To generate job-role specific cover letters

## 🧠 System Architecture

```
User Input → Text Processing → Resume Generator → Cover Letter Generator → Output Display
```

### Workflow:

1. User enters personal details.
2. System processes the input.
3. AI logic generates structured resume content.
4. Cover letter is generated based on job role.
5. Output is displayed in professional format.

## 🚀 Installation Guide



### Step 1: Open Project Folder

```
cd AI-Resume-Cover-Letter-Generator
```

### Step 2: Install Dependencies

```
pip install -r requirements.txt
```

### Step 3: Run Application

```
streamlit run app.py
```

The application will automatically open in your browser.
